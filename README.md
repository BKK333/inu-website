# INU — The Next Generation University Website

موقع تجريبي متكامل لجامعة إربد الأهلية، مبني باستخدام React + Vite + TypeScript، مع خادم Express وتخزين محلي في ملف JSON؛ لا يحتاج إلى أدوات C++ أو Visual Studio.

## التشغيل

يتطلب Node.js 20 أو أحدث. يعمل هذا الإصدار أيضاً مع Node.js 26، ولا يستخدم مكتبات قاعدة بيانات تحتاج إلى بناء native modules.

```bash
npm install
npm run dev
```

- الواجهة: http://localhost:5173
- واجهة API: http://localhost:4000/api/health
- لوحة الإدارة: http://localhost:5173/admin

يمكن أيضاً تشغيل الواجهة والخادم كلٌ على حدة عبر `npm run dev:client` و`npm run dev:server`.

## حساب الإدارة المحلي

لأغراض التطوير فقط، القيم الافتراضية:

- Username: `admin`
- Password: `INU-ChangeMe-2026!`

غيّر `ADMIN_USER` و`ADMIN_PASSWORD` و`SESSION_SECRET` في متغيرات البيئة قبل أي نشر. لا تستخدم هذه القيم على خادم عام. الحساب يُنشأ أول مرة في قاعدة البيانات `backend/inu.sqlite`.

## المزايا الموجودة

- واجهة عربية RTL مع تبديل اتجاه الصفحة واللغة إلى LTR عند اختيار English (النصوص الإنجليزية التفصيلية قابلة للتوسعة).
- تصميم متجاوب، بحث فوري محلي، صفحات داخلية للكليات والبرامج والأخبار.
- صفحات الجامعة، القبول، البحث العلمي، الحياة الجامعية، التواصل، الأسئلة الشائعة، الخدمات والخريجين.
- نموذج اهتمام ونموذج تواصل تجريبيان؛ لا يرسلان بيانات إلى الجامعة.
- لوحة إدارة أخبار مرتبطة بملف بيانات محلي `backend/data/store.json`، مع تسجيل دخول وإضافة وحذف.
- الشعاران المرفقان محفوظان محلياً في `frontend/public/logos`.
- لا توجد روابط تنقل خارجية داخل الواجهة. لا تعتمد الصور أو الشعارات على CDN.

## مصادر المحتوى وملاحظات الدقة

تم بناء المعلومات التعريفية على البيانات المقدمة في طلب المشروع، ومراجعة صفحات الجامعة الرسمية المتاحة حتى 25 نوفمبر 2026. ظهرت اختلافات بين صفحات الكليات الرسمية: صفحة حديثة تعرض 9 كليات، بينما صفحة أخرى تعرض 8 في وصفها رغم إدراج تسعة أسماء؛ لذلك يعرض الموقع أسماء الكليات التسعة الواردة في قائمة الصفحة الحديثة، ويجب على إدارة الجامعة اعتماد القائمة النهائية.

- https://inu.edu.jo/university-colleges/
- https://inu.edu.jo/admissions-registration-university-fees/
- https://inu.edu.jo/all-programs-2/
- إعلانات الجامعة للعام 2026/2027 بشأن البرامج المستحدثة والرسوم.

رسوم البرامج وعدد الساعات وحدود القبول لا تظهر إلا عندما توفر مصدر منشور. حالة بعض البرامج المستحدثة موسومة للتأكد، ولا تعامل موافقة الاستحداث على أنها اعتماد أو طرح نهائي. الإحصائيات ليست لحظية. بيانات الأخبار الأولية مقتطفات تعريفية وليست بديلاً عن النسخ الصحفية الأصلية الكاملة.

## بنية المشروع

- `frontend/`: تطبيق React وملفات الواجهة والأصول المحلية.
- `backend/server.ts`: API والمصادقة التجريبية.
- `backend/data/store.json`: يُنشأ تلقائياً عند أول تشغيل لحفظ الأخبار وحساب الإدارة.

## ملاحظات أمنية للإنتاج

هذا إصدار تجريبي محلي، وليس منصة جامعية إنتاجية جاهزة. قبل النشر يلزم إعداد HTTPS، وتخزين أسرار قوية خارج المستودع، وتغيير مخزن جلسات Express إلى مخزن دائم، وإضافة CSRF وحماية معدل الطلبات وسجل تدقيق وصلاحيات مفصلة ونسخ احتياطي، وربط نماذج القبول والتواصل بأنظمة الجامعة المعتمدة. صفحة الإدارة الحالية تدير الأخبار فقط؛ بقية الأقسام تعرض بيانات ثابتة محلية.


## النشر على الإنترنت عبر Render

تم تجهيز `render.yaml` لنشر الواجهة والخادم في خدمة واحدة:
- أمر البناء: `npm install && npm run build`
- أمر التشغيل: `npm start`
- فحص الصحة: `/api/health`
- خادم Express يقدّم ملفات React المبنية من `dist`، ويعيد `index.html` لمسارات React Router.

الخطوات:
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد (لا ترفع `node_modules`).
2. في Render اختر New + ثم Blueprint، واربط مستودع GitHub.
3. عند طلب القيم السرية أدخل `ADMIN_USER` و`ADMIN_PASSWORD` بقيم قوية وفريدة. لا تستخدم كلمة المرور الافتراضية أو كلمة مرور حساباتك الشخصية.
4. اترك Render ينفّذ البناء والنشر، ثم افتح رابط `onrender.com` الذي يعطيك إياه.

ملاحظات مهمة:
- الخطة المجانية مناسبة للعرض والتجربة فقط؛ قد تتوقف الخدمة عند عدم الاستخدام، وقد يستغرق أول فتح بعد الخمول وقتاً.
- تخزين الأخبار الحالي ملف JSON على نظام الملفات. في الخطة المجانية قد تضيع الأخبار والجلسات عند إعادة تشغيل الخدمة أو إعادة النشر. لحفظ البيانات بشكل دائم، يلزم إعداد تخزين دائم/قاعدة بيانات مناسبة قبل الاعتماد الفعلي.
- جلسات الإدارة تستخدم مخزن Express الافتراضي في الذاكرة، وهو مناسب للتجربة وليس للإنتاج الحساس. لا تستخدم هذا النموذج لتخزين بيانات الطلبة أو المعاملات الرسمية.
- هذا الموقع نموذج تجريبي مستقل، وليس نظاماً رسمياً تابعاً للجامعة ما لم تتم مراجعته واعتماده من الجامعة.
